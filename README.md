# Paradise Nursery

Paradise Nursery is an online plant shopping application built using React and Redux.

## Features
- Browse plants across different categories.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View total items and total price.
- Responsive user interface.

## Technologies Used
- React
- Redux Toolkit
- React Router
- JavaScript
- CSS
- Vite

## Run Locally
1. Clone this repository.
2. Install dependencies using `npm install`.
3. Start the application using `npm run dev`.
